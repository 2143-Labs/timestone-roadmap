Now (Currently working on this)

14

Fewer desyncs and crashes

large job

The biggest job. Each character's known problems are in the character table further down.

  • Fix the character-specific desyncs and crashes listed in the character table
  • 163 fixes and open bugs are marked for re-testing in recent releases. If you still hit one, report it on Discord
  • Stability hardening under the hood: memory use, crash guards, and a fallback when the graphics mode fails

Smoother long sessions

large job

Performance over a long night of sets.

  • Long sets and rematches dropping from 60 to 30 FPS
  • Effects costing more to rewind than they used to(fix released, confirming)

Lobbies and social

medium job

Building on the in-game lobby from v0.6.

  • Return to the room you came from after a set, and keep the lobby list current
  • Private rooms with a password or a generated room code
  • Join by pasting a lobby link in game, plus an in-game invite button (Copy Lobby Link now gives a short shareable link)
  • Name each setup and give it its own set length, so a big room can mix beginner and long-set setups
  • Turn Galactus on or off per room
  • Room skill level and a casual or serious tag
  • A join sound and a "player joined" notice that stays on screen
  • Wired or Wi-Fi connection icon in game (network stats are on the Settings screen)
  • Discord Rich Presence: show your room and match in Discord, with an on/off setting. Built and being updated for v0.6.9; not in a release yet

Next (Starts after the current work)

17

Replays

large job

The game already records each match's inputs while you play; that is how spectating works. Saving matches as files and watching them later from a Gallery menu entry, like the Vita version, has not started yet. Replays may only play back on the version they were recorded with.

  • Save a match as a replay file and watch it again from the Gallery menu

Matchmaking and ranked

large job

The ranking server is built, though its live server needs updating; the in-game side has not started. Lobbies stay the main way to play.

  • Unranked quick match: one button that drops you into an open room setup with someone waiting
  • Separate ranked and unranked queues, with a rating and a leaderboard
  • Both players' results checked, with replays to settle disagreements
  • Ladder rules, such as first-to-4 sets
  • Reports, anti-cheat and anti-smurf measures

Controllers and inputs

medium job
  • Button check in team setup and character select before a match starts
  • Pad working in menus but not in the match after leaving a room match
  • Pads not detected online (PS4, Brook UFB and others)(fix released, confirming)
  • Reconnect a controller after it disconnects
  • Button bindings resetting when a match starts(fix released, confirming)
  • Inputs freezing for a second or two in long online sets
  • Steam Deck: external controller order and player 2 input

Training mode

medium job
  • Start training mode from Timestone directly
  • Train in an empty lobby setup while waiting, or open a training room so someone can join and coach
  • Practise with online input delay and simulated rollback
  • Save states and custom starting positions

Changed or removed

  • Choosing your own rollback frames was removed in v0.6.2. Everyone now uses the same fixed window.
  • The RenderingThread option was removed in v0.6.3.
  • The Direct3D 9Ex graphics mode can still hitch for a second or two when loading on some PCs; optimization work is ongoing.
  • Rocket Raccoon's tail physics have been switched off online since v0.5.0 to avoid desyncs. This can change how some of his attacks connect.
  • Cyrillic names cannot be displayed because the game's built-in font has no Cyrillic glyphs.
  • Spectating, achievements and the shared frame clock shipped before they were tested in real matches. Report anything odd on Discord.
